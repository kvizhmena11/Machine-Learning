## 🎯 Feature Selection


მონაცემების დიდი განზომილების გამო, გამოვიყენე ორეტაპიანი Feature Selection-ის მიდგომა, რაც დამეხმარა მოდელის სისწრაფის გაზრდასა და Overfitting-ის შემცირებაში.

-  ფილტრაციის მეთოდი
პირველ ეტაპზე გამოვიყენე სტატისტიკური ფილტრაცია, რათა მომეშორებინა აშკარად უსარგებლო ინფორმაცია, კერძოდ წავშალე ყველა სვეტი სადაც 90%-ზე მეტი მონაცემი აკლდა. ასევე წავშალე სვეტები , რომლებსაც მხოლოდ 1 უნიკალური მნიშვნელობა ჰქონდათ.

- მოდელზე დაფუძნებული სელექცია
xgboost-ის შემთხვევაში მაგალითად გამოვიყენე Feature Importance,რაც მდგომარეობს იმაში, რომ რადგან მონაცემები დიდია, გამოვიყენე 10%-იანი Sample და მასზე გავწვრთენი სწრაფი XGBoost მოდელი. ამან საშუალება მომცა, ამომეგდო ისეთი ცვლადები, რომლებიც მოდელისთვის ხმაურს წარმოადგენდნენ.

## 🚀 მოდელის წვრთნა და ექსპერიმენტები (Training)


მოდელის წვრთნის პროცესში ჩემი მთავარი მიზანი იყო არა მხოლოდ მაღალი სიზუსტის მიღწევა, არამედ Overfitting-ის  კონტროლი. ყველა ექსპერიმენტი დალოგირებულია MLflow-ში, რაც საშუალებას გვაძლევს თვალი ვადევნოთ მეტრიკებსა და ჰიპერპარამეტრებს.


-   ტესტირებული მოდელები
ექსპერიმენტების ფარგლებში განვიხილე XGBoost-ის ოთხი ძირითადი კონფიგურაცია, რათა შემესწავლა მოდელის ქცევა: Underfit,Overfit, Best , Reduced Overfit: საბოლოო, ყველაზე სტაბილური მოდელი.

- Hyperparameter ოპტიმიზაციის მიდგომა
ოპტიმიზაციისთვის გამოვიყენე Manual Search და Regularization ტექნიკები. ძირითადი პარამეტრები, რომლებზეც მოვახდინე ფოკუსირება იყო max_depth: სიღრმის შეზღუდვა 6-მდე Overfitting-ის შესამცირებლად, ასევე მონაცემების შემთხვევით შერჩევა და L1 L2 რეგულარიზაცია.

- საბოლოო მოდელის შერჩევის დასაბუთება

გრაფიკებზე დაყრდნობით, ჩემს საბოლოო არჩევნად შეჩერდა ReducedOverfit მოდელი. როგორც მეორე გრაფიკზე (მწვანე სვეტი) ჩანს, ამ მოდელს აქვს ყველაზე დაბალი სხვაობა საწვრთნელ და სატესტო შედეგებს შორის (0.0256), რაც 0.05-იან ზღვარზე ბევრად დაბალია. ასევე ისიც ასაღნიშნია, მიუხედავად იმისა, რომ "Best" მოდელს ჰქონდა უფრო მაღალი Validation AUC (0.9074), მისი Overfit Gap (0.0875) მიუთითებდა იმაზე, რომ ის რეალურ, ახალ მონაცემებზე ნაკლებად საიმედო იქნებოდა.
